# 沈锦天 IAN — 个人音乐作品集

一个深色、简洁的个人介绍网页，展示音乐制作方向、精选作品与合作联系方式。当前为可预览版本，尚未正式部署。

## 页面内容

- 首页：沈锦天 IAN 的姓名、录音棚工作照与制作方向。
- 代表合作：向云端、唯爱、角色、山水同路。
- 精选作品：音乐、影视、舞台与综艺三类，可切换查看；点击作品可查看岗位及资料来源。
- 关于：优化后的个人简介与工作范围。
- 联系：邮箱、电话及复制按钮；邮箱链接调用本机邮件程序，电话链接调用可用的拨号程序。

本版本没有音频播放器或联系表单，不依赖第三方服务、外部字体或框架。

## 本地预览

在仓库根目录执行以下命令（需 Python 3）：

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

打开 <http://127.0.0.1:8765/>。使用 `Ctrl+C` 停止预览服务。

也可以双击 `dist/index.html` 离线查看。复制功能受浏览器权限影响，失败时页面会显示可手动复制的信息。

## 文件结构与修改方式

```text
dist/
  index.html        页面结构、个人简介和联系方式
  styles.css       深色主题、排版和响应式布局
  data.js          作品名称、艺人、岗位、图片和来源链接
  site.js          分类切换、作品详情与复制功能
  assets/          本人提供的照片、封面及项目海报
docs/
  content-sources.md 内容来源、署名核对与待确认事项
AGENTS.md          本仓库的协作规则
```

修改作品时，编辑 `dist/data.js` 中对应的列表。新增图片请放入 `dist/assets/`，并填写匹配的相对路径。修改姓名、简介或联系方式时，编辑 `dist/index.html`。本项目的 `dist/` 存放可直接使用的静态源码，已从 `.gitignore` 的忽略规则中移除。

## 检查方式

- 打开桌面及手机尺寸预览，检查中文、换行、图片和横向溢出。
- 切换全部作品分类，打开和关闭详情，检查来源链接。
- 用键盘 Tab/Enter/Escape 验证按钮、弹窗与焦点返回。
- 检查邮箱及电话链接、复制成功和失败提示。
- 如已安装 Node.js，可执行 `node --check dist/data.js` 和 `node --check dist/site.js` 检查脚本语法。

## 内容依据

个人简介、100+ 项目经验、联系方式与原始视觉素材来自本人提供的简介 PDF。对外公开的作品岗位以个人履历和可靠发行署名分别标记，具体来源见 `docs/content-sources.md`。

封面与项目海报用于展示本人履历中的参与项目，其原始权利归相应权利人。照片沿用本人提供的素材。本版本未上传原始 PDF。

## 与 Codex 协作

可以直接提出需求，例如：“把配唱制作放到首页更突出的位置”“在音乐作品中补充这首歌和我的准确岗位”“保留深色，缩短简介并调整手机排版”。修改后应执行相关检查，并解释修改内容。

不要将密码、API 密钥或访问令牌提交到仓库。`.gitignore` 只能帮助忽略未跟踪文件，不能移除已提交的敏感信息。
