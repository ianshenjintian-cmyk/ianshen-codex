# ianshen-codex

这是一个用于与 Codex 协作、学习编程和逐步构建项目的仓库。

## 当前状态

仓库已完成基础初始化，尚未加入应用代码，因此目前没有安装、运行或测试命令。后续选定项目和技术栈后，将在此补充具体步骤。

## 文件说明

- `README.md`：项目介绍、使用说明和当前状态。
- `.gitignore`：忽略常见本地配置、依赖、生成文件和敏感信息文件。
- `AGENTS.md`：Codex 在本仓库工作时应遵循的协作规则。

## 如何与 Codex 协作

提出任务时，说明目标、期望结果和需要保留的行为。例如：

- “做一个中文个人介绍网页，包含简介、作品和联系方式，并说明如何预览。”
- “解释项目的目录结构和运行步骤，适合初学者阅读。”
- “修复这个报错，检查修改结果，并解释原因。”
- “在新分支上增加深色模式并创建 PR，说明验收步骤。”

建议流程：提出需求 → 实现修改 → 检查结果 → 查看修改说明 → 提交或通过 PR 审阅。

## 凭据和配置

不要将密码、API 密钥、访问令牌或真实凭据提交到仓库。如需环境变量，使用本地 `.env` 文件，并提供不含真实凭据的 `.env.example` 作为配置模板。

`.gitignore` 只能帮助忽略未跟踪文件，不能移除已提交的敏感信息。
